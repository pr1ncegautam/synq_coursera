# Synq --- Ghost Protocol

Synq is a Chrome extension built to automate Coursera video completion
and reduce repetitive manual effort when working through course lessons.

## Who is it for?

Synq is intended for Coursera learners who want a more convenient way to
handle video-completion tasks while navigating their coursework.

## What it does

-   Automates Coursera video-completion tasks.
-   Provides a simple, focused workflow through the extension popup.
-   Shows status feedback while the task is running.

Synq focuses on video completion. It does not provide AI quiz answering
or graded-assignment solving.

## Installation

1.  Download or clone this repository.
2.  If you downloaded a ZIP, extract it to a folder.
3.  Open `chrome://extensions` in Chrome.
4.  Turn on **Developer mode**.
5.  Select **Load unpacked**.
6.  Choose the folder containing the extension's `manifest.json` file.

## How to use

1.  Open Coursera in Chrome and navigate to the course video you want to
    work with.
2.  Click the Synq extension icon.
3.  Start the video-completion workflow and follow the status shown by
    the extension.

The exact behavior may depend on the course page and the current version
of Coursera.
